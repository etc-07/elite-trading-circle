# Elite Trading Circle 🚀

> **Catatan:** Repository ini adalah versi showcase/portfolio dari platform komunitas trading eksklusif.

## 📌 Tentang Project
Elite Trading Circle adalah platform web berbasis PWA (Progressive Web App) yang dikembangkan untuk kebutuhan komunitas trading. Platform ini menyediakan antarmuka untuk monitoring akun, manajemen informasi EA (Expert Advisor), dan dashboard pengguna yang responsif.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **PWA:** Service Worker (`sw.js`) & Web App Manifest untuk kemampuan offline & installable
- **Architecture:** Multi-page Application (MPA) dengan struktur modular
- **Deployment:** GitHub Pages

## ✨ Fitur Utama
- 🔐 **Authentication Flow:** Halaman Login & Register yang terintegrasi
- 📊 **Dashboard:** Antarmuka monitoring untuk anggota komunitas
- 📱 **PWA Ready:** Dapat di-install sebagai aplikasi di perangkat mobile/desktop
- 🎨 **Responsive Design:** Optimal di berbagai ukuran layar (mobile-first approach)

## 💡 Technical Highlights (Untuk Recruiter)
- Implementasi **Service Worker** untuk caching aset dan pengalaman pengguna yang lebih cepat.
- Struktur file yang terorganisir untuk skalabilitas fitur ke depannya.
- Fokus pada *clean UI* dan *user experience* untuk pengguna non-teknis (trader).
